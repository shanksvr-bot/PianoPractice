# PianoPractice

A piano practice assistant that listens to keyboard
performances and identifies musical notes.

## Features

- Microphone audio input
- Real-time pitch detection
- Musical note identification
- Octave identification
- Frequency display
- Installable Progressive Web App

## Technology

- HTML
- CSS
- JavaScript
- Web Audio API
- YIN pitch detection

## Hosting

GitHub Pages

## Planned Features

- Sheet music upload
- Sheet music recognition
- Automatic note highlighting
- Chord recognition
- Practice tracking
